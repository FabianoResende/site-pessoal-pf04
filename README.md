# Site Pessoal PF-04

Site pessoal de Fabiano Faria de Resende, desenvolvido para a atividade PF-04 do programa FlyRank.

## Objetivo

Apresentar meu posicionamento profissional, meu processo de trabalho, projetos selecionados e canais de contato em uma página pública, responsiva e acessível.

## Posicionamento

Frontend, inteligência artificial aplicada e automação.

Transformo evidências dispersas em recomendações para decisão.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Netlify
- Calendly

## Estrutura

```text
site-pessoal-pf04/
├── assets/
│   ├── documents/
│   │   └── CV_Fabiano_Faria_de_Resende.pdf
│   └── images/
├── GUIDE_DNS.md
├── index.html
├── README.md
├── script.js
└── styles.css
```

## Arquivos principais

### `index.html`

Contém a estrutura semântica e o conteúdo do site:

- apresentação profissional;![alt text](image-1.png)
- problema que orienta meu trabalho;
- método de trabalho;
- projetos selecionados;
- seção sobre;
- contatos;
- espaço para publicações futuras.

### `styles.css`

Define:

- identidade visual;
- layout responsivo;
- cartões;
- botões;
- foco visível;
- estados de interação;
- suporte a `prefers-reduced-motion`.

### `script.js`

Responsável por:

- atualizar automaticamente o ano no rodapé;
- identificar a seção visível;
- marcar o item correspondente na navegação.

### `GUIDE_DNS.md`

Explica, em linguagem acessível:

- DNS;
- resolvedor;
- servidores de nomes;
- registros DNS;
- CNAME;
- hospedagem;
- HTTPS;
- fluxo entre navegador e servidor.

## Execução local

O site não possui dependências nem etapa de compilação.

Para abrir localmente:

1. Abra a pasta do projeto.
2. Localize o arquivo `index.html`.
3. Abra o arquivo em um navegador.
